## Key Concept: Manual Experiment Tracking

In v6 we saved the model. Now we also save metrics separately for tracking experiments:

```
v6 saves to models/:     Pipeline pickle + basic metadata
v7 saves to results/:    Detailed metrics + params + dataset info
```

This is the **manual way** to track experiments. You manage files, naming, timestamps yourself.

> **Good to know:** tools like MLflow (not part of this course) replace both v6 + v7 with:
> ```python
> mlflow.log_metrics(metrics)
> mlflow.log_params(model_params)
> mlflow.sklearn.log_model(pipeline)
> ```
> Three lines instead of two separate save functions. That's the power of MLflow.
